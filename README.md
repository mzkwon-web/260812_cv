# 권영지 CV — GitHub Pages

정적 HTML/CSS/JS로 구성된 개인 CV 웹사이트입니다.

## 파일
- `index.html` — CV 본문
- `style.css` — 디자인
- `script.js` — 스크롤 등장 효과 및 현재 연도 표시

## GitHub Pages 배포
1. GitHub에서 새 Repository를 만듭니다.
2. 세 파일을 Repository 루트에 업로드합니다.
3. `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 선택하고 저장합니다.
6. 잠시 후 GitHub Pages 주소가 생성됩니다.

## 개인정보
공개 CV에는 주민등록번호와 계좌번호를 넣지 않았습니다.
연락처는 공개가 부담스럽다면 `index.html`에서 삭제하거나 이메일만 남겨도 됩니다.
